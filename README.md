# sechenov-volley-bot

Telegram-бот [@sechenov_volley_bot](https://t.me/sechenov_volley_bot) для расписания, подписок и учёта планируемого участия в играх и тренировках.

Лиги: **МССИ, ЛВЛ, ЧМ, ЛЧБ**. Команды: Сеченовский университет и Росэнергоатом для ЛЧБ. Тренировки: понедельник и четверг, **19:30 МСК**, **Буревестник**.

[Архитектура и критерии приёмки](docs/superpowers/specs/2026-10-17-sechenov-volley-bot-design.md).

## Размещение

- Приватный GitHub: код, документация и постоянные данные бота.
- Google Apps Script: обработка команд, синхронизация и напоминания.
- Google Sheets: исходное расписание.
- GitHub Actions: будущие проверки, сборка и публикация после настройки Google-доступа.

Локальная копия проекта не требуется. Секреты не включаются в Git-файлы: они настраиваются отдельно в защищённых настройках.

## Состояние проекта

Опубликована архитектурная спецификация. Реализация, развёртывание и рассылки ещё не выполнены.
