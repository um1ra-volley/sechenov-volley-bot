# Загрузка ЧМ и выбор всех лиг

Дата: 17 октября 2026. Ветка доставки — main.

## Причина сбоя ЧМ

Источник — «Чемпионат Москвы по волейболу — сезон 2026/2027», лист «Высшая лига (муж, гр Б)», gid 2047287896.
Перед расписанием на том же листе размещена турнирная таблица: строки 4–9 имеют числовой номер в A,
но название команды расположено в D. Проверка каждой числовой строки как матча с командами в I/S
отклоняла эти строки и весь импорт сообщением «Не удалось прочитать расписание ЧМ».

Данные прочитаны в режиме просмотра через интерфейс Google Таблиц, диапазон A1:AR300, без изменения таблицы.
Заголовок расписания находится в строке 11: A «№ игры», E «Дата», I «Команда №1», S «Команда №2».
Строки Сеченовского университета в самом расписании: 13, 16, 22, 25, 26 — пять игр.
В частности, игра №41 — 24.10.2026, 11:45 МСК, СШ Москва 98, Алабяна 13к1.
Верхняя строка команды №3 в турнирной таблице не является матчем.

Исправление: находить единственный заголовок расписания по A/E/I/S и разбирать только строки после него.
Проверки ширины игровой строки, обеих команд, уникального номера, даты, времени и точного названия вуза сохранены.
Изменившаяся структура или повреждённая игровая строка по-прежнему сохраняют последний снимок вместо ложного удаления игр.
Ошибки транспорта теперь отделены от ошибки формата без вывода URL, токенов или тела ответа.

## Подписки

Новый выбор содержит «Все лиги», «Тренировки», «Готово».
«Все лиги» включает МССИ, ЛВЛ, ЧМ, ЛЧБ; повторное нажатие отключает только эти четыре лиги.
Тренировки не затрагиваются. В состоянии сохраняются обычные идентификаторы лиг, не виртуальное значение ALL.
Старые отдельные подписки сохраняются; их старые кнопки показывают обновлённый выбор.

## Граница проверки

Выполнено чтение настоящего листа и статический просмотр исходников. Бот, тесты и Docker не запускались.
Фактическую загрузку на сервере друга следует смотреть после обновления main и команды /sync или ближайшей проверки.
